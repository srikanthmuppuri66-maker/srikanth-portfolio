Featured Project

Catching anomalies before they cause damage

Real-Time Anomaly Detection in IoT Sensor Data

Dec 2025 – Apr 2026

An unsupervised anomaly detection system that analyzes multivariate IoT sensor data using an LSTM Autoencoder. The model learns what "normal" sensor behavior looks like, then flags readings that don't fit the pattern — useful for predictive maintenance, where catching a problem early matters more than explaining it perfectly.

Built a full pipeline: MinMax scaling and sliding-window sequence generation for preprocessing, reconstruction-error scoring for detection, and a modular Python architecture so each stage (preprocessing, inference, visualization) can be tested on its own. Deployed it with Streamlit and Plotly for live, interactive monitoring.
